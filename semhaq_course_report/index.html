基于 YOLO 的自动驾驶感知系统：车辆计数与目标检测

摘要

本文档详细记录了在《基础软件和开源系统》课程中，围绕 OpenHUTB/nn 开源仓库完成的系列贡献工作。项目聚焦于自动驾驶感知领域，完成了两个核心子系统：基于 YOLO11n 的多版本车辆计数系统和基于 YOLO12 的 CARLA 数据集目标检测实验。

车辆计数系统从基础版本迭代至五个功能版本（原版、改进版、上下行版、CARLA 版、区域版），并集成了精度衡量功能。YOLO12 目标检测项目则完成了从数据集配置、Baseline 训练验证到两种改进模型（A2C2f-CGLU、A2C2f-DFFN）设计的完整研发流程。

整个项目历时一个月（2026年3月14日 - 4月13日），共提交 11 个 Pull Request 并全部合并，累计新增代码超过 36 万行，涵盖工程开发、模型训练、性能评估与开源协作的全生命周期。

1. 项目背景与立项依据

1.1 课程实践背景

本项目源于《基础软件和开源系统》课程的实践要求，旨在通过向开源社区（OpenHUTB/nn）贡献高质量的代码与文档，完整走通 "Issue 分析 -> 分支管理 -> 功能开发 -> 测试验证 -> 文档撰写 -> Pull Request 提交" 的标准化软件工程流程。

OpenHUTB/nn 是湖南工商大学的神经网络教学与科研平台，使用神经网络实现感知、规划和控制功能，覆盖 Carla（自动驾驶）、AirSim（无人机）和 MuJoCo（人形机器人）三大模拟器。

1.2 技术背景

在自动驾驶感知系统中，车辆检测与计数是交通流量分析、智能交通管理的基础能力。传统方法依赖于背景减除或光流法，受光照变化和遮挡影响较大。YOLO 系列模型作为单阶段目标检测的代表，以高精度和实时性成为该领域的主流方案。

本项目选取两个技术方向切入：

  • YOLO11n 车辆计数：基于 YOLO11n 轻量化模型，构建多场景、多功能的车辆计数管线，验证从基础检测到复杂场景计数的工程化能力。
  • YOLO12 目标检测：基于最新的 YOLO12 架构，在 CARLA 模拟器生成的数据集上进行训练与改进，探索注意力机制增强的检测模型。

1.3 技术选型

2. 项目一：YOLO11n 多版本车辆计数系统

2.1 项目概述

本项目基于 YOLO11n 构建了一套可扩展的车辆计数系统，通过 --version 参数切换不同计数模式，逐步迭代出五个功能版本。系统支持实时视频处理、车辆轨迹绘制、多区域计数以及精度评估。

使用方法：

F1 Score 2 * (Precision * Recall) / (Precision + Recall) 精确率与召回率的调和平均

3.5 模型改进

在 Baseline 基础上，提出了两种改进方案，通过替换 YOLO12 中的标准 A2C2f 模块实现性能提升。

3.5.1 A2C2f-CGLU 改进模型（PR #5276）

改进思路：

CGLU（Convolutional Gated Linear Unit）是一种结合卷积操作和门控线性单元的模块。其核心思想是通过门控机制增强特征选择能力：

标准 A2C2f:          A2C2f-CGLU:
Input                 Input
  ↓                     ↓
Conv → BN → SiLU     Conv → BN → SiLU
  ↓                     ↓
Conv → BN → SiLU     GLU Gate (σ(x) ⊙ x)
  ↓                     ↓
Output                Conv → BN → SiLU
                        ↓
                      Output

技术优势：

  • 门控机制：通过 sigmoid 门控选择性地保留重要特征，抑制噪声
  • 小目标增强：门控机制有助于提升小目标（如远处车辆、交通标志）的检测精度
  • 参数效率：GLU 结构在增加少量参数的同时显著提升表达能力

配置文件 yolo12-A2C2f-CGLU.yaml：

  • 使用 A2C2f_CGLU 模块替换标准 A2C2f 模块

3.5.2 A2C2f-DFFN 改进模型（PR #5303）

改进思路：

DFFN（Deep Feed-Forward Network）通过加深前馈网络的层数来增强模型的非线性表达能力：

标准 A2C2f:          A2C2f-DFFN:
Input                 Input
  ↓                     ↓
Conv → BN → SiLU     Conv → BN → SiLU
  ↓                     ↓
Conv → BN → SiLU     FFN Layer 1 (Conv → GELU)
  ↓                     ↓
Output                FFN Layer 2 (Conv → GELU)
                        ↓
                      Residual Connection
                        ↓
                      Output

技术优势：

  • 深层非线性：多层 FFN 结构增强了模型对复杂模式的拟合能力
  • 残差连接：保留梯度流，避免深层网络的退化问题
  • 复杂场景适应：深层结构有助于处理复杂背景和多类别检测

配置文件 yolo12-A2C2f-DFFN.yaml：

  • 使用 A2C2f_DFFN 模块替换标准 A2C2f 模块
  • 预设模型类别数为 5，适配 CARLA 数据集
  • 与 CGLU 模型共存于项目中，支持对比实验

运行效果：

3.6 两种改进方案对比

特性 A2C2f-CGLU A2C2f-DFFN
核心思想 门控线性单元增强特征选择 深层前馈网络增强非线性
改进模块 CGLU (Convolutional Gated Linear Unit) DFFN (Deep Feed-Forward Network)
关键机制 Sigmoid 门控 + 逐元素乘法 多层 FFN + 残差连接
适用场景 小目标、密集场景 复杂背景、多类别
参数开销 较低 中等
梯度流 门控天然保持梯度 残差连接保持梯度
预期优势 提升小目标检测精度 提升复杂场景检测能力
