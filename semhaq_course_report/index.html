基于 YOLO 的自动驾驶感知系统：车辆计数与目标检测

摘要

本文档详细记录了在《基础软件和开源系统》课程中，围绕 OpenHUTB/nn 开源仓库完成的系列贡献工作。项目聚焦于自动驾驶感知领域，完成了两个核心子系统：基于 YOLO11n 的多版本车辆计数系统和基于 YOLO12 的 CARLA 数据集目标检测实验。

车辆计数系统从基础版本迭代至五个功能版本（原版、改进版、上下行版、CARLA 版、区域版），并集成了精度衡量功能。YOLO12 目标检测项目则完成了从数据集配置、Baseline 训练验证到两种改进模型（A2C2f-CGLU、A2C2f-DFFN）设计的完整研发流程。

整个项目历时一个月（2026年3月14日 - 4月13日），共提交 11 个 Pull Request 并全部合并，累计新增代码超过 36 万行，涵盖工程开发、模型训练、性能评估与开源协作的全生命周期。

1. 项目背景与立项依据

1. 1 课程实践背景

本项目源于《基础软件和开源系统》课程的实践要求，旨在通过向开源社区（OpenHUTB/nn）贡献高质量的代码与文档，完整走通 "Issue 分析 -> 分支管理 -> 功能开发 -> 测试验证 -> 文档撰写 -> Pull Request 提交" 的标准化软件工程流程。

OpenHUTB/nn 是湖南工商大学的神经网络教学与科研平台，使用神经网络实现感知、规划和控制功能，覆盖 Carla（自动驾驶）、AirSim（无人机）和 MuJoCo（人形机器人）三大模拟器。

1. 2 技术背景

在自动驾驶感知系统中，车辆检测与计数是交通流量分析、智能交通管理的基础能力。传统方法依赖于背景减除或光流法，受光照变化和遮挡影响较大。YOLO 系列模型作为单阶段目标检测的代表，以高精度和实时性成为该领域的主流方案。

本项目选取两个技术方向切入：

  • YOLO11n 车辆计数：基于 YOLO11n 轻量化模型，构建多场景、多功能的车辆计数管线，验证从基础检测到复杂场景计数的工程化能力。
  • YOLO12 目标检测：基于最新的 YOLO12 架构，在 CARLA 模拟器生成的数据集上进行训练与改进，探索注意力机制增强的检测模型。

1. 3 技术选型

技术/工具 用途
Python 3.11+ 核心开发语言
Ultralytics YOLO YOLO11n / YOLO12 模型框架
OpenCV 视频处理与可视化

2. 项目一：YOLO11n 多版本车辆计数系统

2. 1 项目概述

本项目基于 YOLO11n 构建了一套可扩展的车辆计数系统，通过 --version 参数切换不同计数模式，逐步迭代出五个功能版本。系统支持实时视频处理、车辆轨迹绘制、多区域计数以及精度评估。

相关 PR：#5169、#5215、#5221、#5229、#5230、#5232、#5236

2. 2 系统架构

系统采用函数式架构设计，以 main.py 为统一入口，通过参数解析分发到不同版本的计数模块：

main.py (统一入口)
├── --version original    → yolo_vehicle_counter.py
├── --version improved    → yolo_vehicle_counter_improved.py
├── --version updown      → yolo_vehicle_counter_updown.py
├── --version carla       → yolo_vehicle_counter_carla.py
└── --version region      → yolo_vehicle_counter_region.py

2. 3 版本迭代详情

2.3.1 原版（PR #5215）

基础版本实现了完整的车辆检测与计数流程：

  • 命令行参数解析（模型路径、输入/输出视频）
  • 实时视频处理，绘制车辆边界框与运动轨迹
  • 实时显示当前车辆计数
  • 支持 'p' 键暂停/恢复

2.3.2 改进版（PR #5221）

在原版基础上增强了可视化效果与区域选择能力：

  • 引入 EllipseAnnotator 椭圆标注替代矩形框，视觉效果更自然
  • 支持多边形 ROI（感兴趣区域），适应复杂监控场景
  • 优化轨迹跟踪与计数逻辑
  • 添加 .gitignore 排除大型模型目录

2.3.3 上下行版（PR #5229）

实现了分方向的车辆计数功能：

  • 基于分区的双向计数：左侧区域（0-550px）统计上行，右侧区域（550-1280px）统计下行
  • 通过 --version updown 参数调用
  • 代码符合 PEP 8 规范，注释完整

2.3.4 CARLA 版（PR #5230）

集成了 CARLA 模拟器支持：

  • carla_launcher.py：优化的车辆生成算法，解决了碰撞/卡死问题，支持生成 100 辆车
  • yolo_vehicle_counter_carla.py：针对 CARLA 录制视频优化，红线位置 y=500，ROI 调优减少天空干扰，置信度阈值降至 0.4
  • 测试环境：Windows 10, Python 3.12, CARLA 0.9.x

2.3.5 区域版（PR #5232）

高级区域计数版本，支持复杂路况：

  • 检测平滑处理，减少计数抖动
  • 双向交通流量统计
  • 多边形区域计数，适应复杂道路布局
  • 自定义可视化增强（半透明叠加层、轨迹标注）
  • 动态区域缩放适配不同分辨率
  • 底部中心计数策略，提升准确性

2. 4 精度衡量功能（PR #5236）

为系统添加了完整的精度评估模块：

  • --ground-truth 参数支持真值文件输入
  • 支持两种格式：简单总数格式和分段验证格式（每行一个数字）
  • 实时显示 ACC 和 F1 指标
  • 处理完成后输出详细精度报告
  • 基于检测置信度的帧级精度计算
python main.py --version original --ground-truth dataset/ground_truth/ground_truth.txt

2. 5 技术亮点

  1. 模块化设计：统一入口 + 版本分发，新增版本无需修改主流程
  2. 渐进式迭代：从基础功能到复杂场景，每个版本解决特定问题
  3. 仿真集成：与 CARLA 模拟器深度集成，形成数据采集到检测验证的闭环
  4. 量化评估：引入精度指标，支持科学的性能对比

3. 项目二：YOLO12 CARLA 数据集目标检测

3. 1 项目概述

本项目基于 YOLO12 架构，在 CARLA 模拟器生成的目标检测数据集上完成从 Baseline 训练到模型改进的全流程实验。

相关 PR：#5263、#5268、#5276、#5303

3. 2 数据集

数据集来源：Carla-Object-Detection-Dataset

包含 5 个类别：

类别 说明
vehicle 车辆
bike 自行车
motobike 摩托车
traffic_light 交通灯
traffic_sign 交通标志

3. 3 Baseline 训练与验证（PR #5263、#5268）

完成了完整的训练验证管线：

  • 创建统一入口 main.py，支持 train、val、predict 三种命令
  • 配置数据集路径与 data.yaml
  • 使用 YOLO12n 作为 Baseline 模型进行训练
  • 完成验证并记录性能指标
python main.py train    # 训练
python main.py val      # 验证
python main.py predict  # 推理

3. 4 模型改进

在 Baseline 基础上，提出了两种改进方案，通过替换 YOLO12 中的标准 A2C2f 模块实现性能提升。

3.4.1 A2C2f-CGLU 改进模型（PR #5276）

  • 新增模型配置 yolo12-A2C2f-CGLU.yaml
  • 使用 CGLU（Convolutional Gated Linear Unit）模块替代标准 A2C2f
  • CGLU 通过门控机制增强特征选择能力，有助于提升小目标检测精度
  • 预配置 5 类别适配 CARLA 数据集

3.4.2 A2C2f-DFFN 改进模型（PR #5303）

  • 新增模型配置 yolo12-A2C2f-DFFN.yaml
  • 使用 DFFN（Deep Feed-Forward Network）模块替代标准 A2C2f
  • DFFN 通过加深前馈网络增强非线性表达能力
  • 与 CGLU 模型共存于项目中，支持对比实验

3. 5 两种改进方案对比

特性 A2C2f-CGLU A2C2f-DFFN
核心思想 门控线性单元增强特征选择 深层前馈网络增强非线性
适用场景 小目标、密集场景 复杂背景、多类别
模块结构 GLU 门控 + 卷积 多层 FFN + 残差

5. 总结与展望

5. 1 工作总结

本课程实践围绕自动驾驶感知系统，完成了以下核心工作：

  1. 车辆计数系统：从零构建了五版本迭代的车辆计数管线，覆盖基础检测、增强可视化、双向计数、仿真集成和区域计数等场景，并集成了量化评估能力。
  2. YOLO12 目标检测：在 CARLA 数据集上完成了 Baseline 训练，提出了两种基于模块替换的改进方案（CGLU 和 DFFN），为后续性能对比实验奠定基础。
  3. 开源协作：严格遵循开源协作规范，完成 11 个 PR 的提交与合并，积累了完整的开源项目贡献经验。

5. 2 未来展望

  • 完成 A2C2f-CGLU 和 A2C2f-DFFN 两种改进模型的训练与性能对比
  • 将车辆计数系统与 YOLO12 检测模型集成，探索更强大的检测 backbone
  • 在 CARLA 中构建更复杂的交通场景进行压力测试
  • 探索多传感器融合（LiDAR + Camera）的感知方案
